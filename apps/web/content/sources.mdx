## How lessons become skills

We identify a specific job, inspect a source, extract the useful decision criteria, and write an original workflow. We add explicit inputs, outputs, evidence checks, and practical constraints where they help an agent do the work.

Before expanding the library, each proposed skill needs a source review and a usable artifact. A catalog entry alone is not a reviewed source. The remaining catalog has not yet been distilled into skills.
